이 도구는 무엇인가요?

업로드 도우미는 YouTube 채널 운영자 본인이 직접 만든 영상을 본인 소유의 YouTube 채널에 예약 업로드하기 위해 쓰는 개인용 프로그램입니다. 운영자의 PC 에서만 실행되며, 운영자 본인 외의 사용자는 없습니다.

하는 일

  • 운영자가 준비한 영상·제목·설명·썸네일을 운영자 본인의 채널에 업로드하고 공개 시각을 예약합니다 (YouTube Data API youtube.upload).
  • 업로드하기 전에 올바른 채널인지 확인하고, 올린 영상의 처리 상태를 확인합니다 (youtube.readonly).

하지 않는 일

  • 다른 사람의 정보를 모으지 않습니다. 광고·판매·제3자 제공이 없습니다.
  • 영상 삭제, 댓글, 구독, 수익 같은 다른 권한은 요청하지 않습니다.

About (English)

Upload Helper is a private tool used only by the channel owner to upload the owner's own videos to the owner's own YouTube channel and schedule their publish time. It runs only on the owner's computer and has no other users. It uses the YouTube Data API scopes youtube.upload (upload videos) and youtube.readonly (confirm the correct channel and check upload status). It does not collect data from anyone else.

See the Privacy Policy and Terms of Service.
