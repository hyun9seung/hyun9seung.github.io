개인정보처리방침

업로드 도우미 (Upload Helper) · 시행일 2026-11-25 · 홈으로

1. 이 도구를 쓰는 사람

업로드 도우미는 YouTube 채널 운영자 본인만 쓰는 개인용 업로드 도구입니다. 다른 사용자를 받지 않습니다.

2. 쓰는 정보 (YouTube API 서비스)

이 도구는 YouTube API 서비스를 사용합니다. 운영자가 본인 구글 계정으로 허용하면 아래 정보만 씁니다.

  • 운영자 본인 YouTube 채널의 채널 ID·채널 이름 — 올바른 채널에 올리는지 확인하는 데 씀
  • 이 도구로 올린 영상의 처리·공개 상태 — 업로드가 제대로 됐는지 확인하는 데 씀
  • 업로드하는 영상·제목·설명·썸네일 — 운영자가 직접 준비한 것

3. 보관과 공유

  • 인증 토큰과 업로드 기록은 운영자의 PC 에만 저장되며, 다른 서버로 보내지 않습니다.
  • 어떤 정보도 판매하거나 제3자에게 제공하지 않습니다. 광고에 쓰지 않습니다.
  • 운영자가 도구를 지우거나 토큰 파일을 삭제하면 함께 없어집니다.

4. 권한 철회

구글 계정의 서드파티 연결 관리 또는 보안 설정 → 계정에 액세스할 수 있는 앱에서 언제든 이 도구의 접근 권한을 해제할 수 있습니다.

5. 함께 적용되는 정책

  • YouTube 서비스 약관
  • Google 개인정보처리방침

6. 바뀔 때

이 방침이 바뀌면 이 페이지의 시행일을 고쳐 알립니다.

Privacy Policy (English)

Upload Helper is a private tool used only by the YouTube channel owner. It uses YouTube API Services. With the owner's permission it uses only: the owner's channel ID and name (to confirm the correct channel), the processing/publishing status of videos uploaded with this tool, and the videos, titles, descriptions and thumbnails the owner prepares. Tokens and upload records are stored only on the owner's computer and are never sent to other servers, sold, shared with third parties or used for advertising.

Access can be revoked at any time at Google security settings. By using this tool you agree to the YouTube Terms of Service; see also the Google Privacy Policy. Effective 2026-11-25.
